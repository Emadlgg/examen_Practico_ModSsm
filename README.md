# Grupo1_PoblacionDesplazada

## Estructura

- `notebook/` — notebook principal (.ipynb) con el modelo.
- `data/` — datos de entrada originales (Excel), sin modificar.
- `outputs/` — resultados exportados (CSV/Excel/gráficas) listos para entregar.
- `requirements.txt` — dependencias necesarias.

## Cómo correrlo

```bash
pip install -r requirements.txt
jupyter notebook notebook/
```
